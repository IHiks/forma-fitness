# Установка Формы на iPhone (без Mac и без Apple Developer Program)

Путь: **GitHub Actions собирает .ipa без подписи → SideStore подписывает его вашим Personal Team → установка на iPhone.**

Вам не нужны: Mac, платная программа Apple ($99/год), платные сервисы. Нужны: Windows-ПК, iPhone, Apple ID, ~30–60 минут времени.

Официальная документация SideStore (проверено 20.10.2026): https://docs.sidestore.io/docs/installation/prerequisites

---

## Шаг 0. Что должно быть заранее

- **Публичный репозиторий** на GitHub с кодом проекта (приватный репозиторий не даёт бесплатных минут Actions).
- Репозиторий содержит `.github/workflows/ios-unsigned.yml` — сборка уже настроена.

## Шаг 1. Запуск сборки

1. Откройте репозиторий на GitHub → вкладка **Actions**.
2. Слева выберите **Build unsigned iOS IPA** → кнопка **Run workflow** → **Run workflow**.
   - Сборка запускается и автоматически при пуше в `main`, и вручную.
3. Дождитесь зелёного статуса (обычно 10–20 минут; первый запуск дольше — кешируются CocoaPods).
4. Если сборка упала — откройте лог шага **Build unsigned IPA**. Если Xcode не тот (редкий случай), workflow сам скажет об этом; тогда в `.github/workflows/ios-unsigned.yml` поменяйте `runner: xcode-27` на `macos-26` (это задокументированный запасной вариант).

## Шаг 2. Скачивание артефакта

После успешной сборки:

- **Вариант А (проще):** Releases → тег вида `v1.0.0-unsigned` → ассеты `Forma.ipa` и `source.json`.
- **Вариант Б:** вкладка Actions → последний запуск → внизу **Artifacts** → `Forma-1.0.0-unsigned` (хранится 3 дня).

Сохраните `Forma.ipa` в «Файлы» iPhone (можно через iCloud Drive, Telegram «Избранное», почту или кабель).

## Шаг 3. SideStore на iPhone

SideStore — открытый (open source) менеджер приложений, который подписывает IPA вашей собственной сертификацией Personal Team. Официальная инструкция: **https://docs.sidestore.io/docs/installation/prerequisites** → Install.

Требования (по официальной документации): iPhone с код-паролем, iOS/iPadOS 15.0+, **подключение по Wi-Fi** (мобильный интернет для установки/обновления не подходит), Apple ID, ПК — только для первоначальной установки.

### 3.1. На iPhone: LocalDevVPN

1. Установите **LocalDevVPN** из App Store (или из источника AltStore PAL).
2. Откройте его и подключитесь к VPN — при запросе «Разрешить конфигурации VPN» нажмите **Разрешить** и введите код-пароль.
   - Этот VPN нужен при каждой установке, обновлении или обновлении подписи (Refresh) в SideStore.

### 3.2. На ПК: iloader

1. Скачайте **iloader** с официального релиза: https://github.com/nab138/iloader/releases/latest — для Windows установщик **`iloader-windows-x64.msi`** (рекомендуется) или `.exe` (всё open source; ссылки даны с официальной документации SideStore).
2. Подключите iPhone кабелем к ПК, на iPhone нажмите «Доверять этому компьютеру» и введите код-пароль.
3. Запустите iloader, войдите в Apple Account (регистр учётной записи имеет значение; пароль от Apple ID вводится только в iloader — я его никогда не спрашиваю и не вижу).
4. Выберите своё устройство → **Install SideStore (Stable)**.

### 3.3. На iPhone: доверие и режим разработчика

1. **Настройки → Основные → VPN и управление устройством** → в разделе «Программы разработчика» выберите свой Apple ID → **Доверять** → «Разрешить и перезагрузить» → подтвердите код-паролем.
2. **Настройки → Конфиденциальность и защита → Режим разработчика** → включите (требуется на iOS 16+) → перезагрузка iPhone.
3. Откройте **LocalDevVPN** → **Connect**.
4. Откройте **SideStore**, войдите в тот же Apple Account.
5. Вкладка **My Apps** → нажмите на счётчик **«7 DAYS»** рядом с SideStore, чтобы обновить подпись и завершить настройку; при запросе на пересоздание/отзыв сертификата нажмите **Yes / Refresh Now**.

## Шаг 4. Установка Формы

Перед установкой: **LocalDevVPN подключён (Connect)**, SideStore открыт, iPhone в сети Wi-Fi.

Способ 1 (через источник):

1. Откройте SideStore → вкладка **Sources** → **+** → добавьте `source.json` (или URL вида `https://github.com/<owner>/<repo>/releases/latest/download/source.json`).
2. Вкладка **My Apps** → Форма → **Install** (если появится «Refresh» — обновите подпись, приложение то же).

Способ 2 (ссылкой):

- Откройте в Safari на iPhone:
  `sidestore://install?url=https://github.com/<owner>/<repo>/releases/latest/download/Forma.ipa`

Способ 3 (файл напрямую):

- В «Файлах» нажмите на `Forma.ipa` → «Поделиться» → SideStore.

## Шаг 5. Что важно знать про подпись

- SideStore подписывает приложение сертификатом **Personal Team**. Apple ограничивает такие сертификаты: приложение «живёт» **7 дней** (бесплатный Apple ID), после чего нужно обновить подпись: iPhone подключён к **Wi-Fi**, **LocalDevVPN → Connect**, SideStore → **My Apps** → тап по счётчику дней рядом с приложением (**Refresh**). ПК для этого не нужен.
- **Лимит бесплатного Apple ID:** одновременно максимум **3 sideloaded-приложения (включая SideStore)** и до 10 новых App ID в неделю. Форма — второе приложение, слот есть.
- Если Apple попросит пересоздать сертификат при Refresh — соглашайтесь (Yes / Refresh Now).
- Если у вас **платная** Apple Developer Program ($99/год) — ограничение снимается до 1 года, но она вам для Формы не нужна.
- SideStore переподписывает само; `_CodeSignature` из сборки удаляется (ваша сборка собирается вообще без подписи — это проверяет `scripts/verify-ipa.mjs`).
- Файл pairing может истечь после обновления или сброса iPhone — тогда установку SideStore повторяют заново по той же инструкции.

## Проверка, что установилось именно то, что нужно

- На iPhone: Настройки → Основные → Управление iPhone → Форма → версия.
- Артефакт проверен автоматически перед публикацией: структура IPA, `CFBundleIdentifier = com.ihiks.forma`, версия, `MinimumOSVersion`, Mach-O arm64, отсутствие профиля подписи, sha256 в `source.json`.

## Возможные проблемы

| Ситуация | Решение |
|---|---|
| Actions недоступен / «Upgrade for more minutes» | Репозиторий приватный → сделайте публичным (или купите план; публичный репозиторий даёт безлимит минут на стандартных runner'ах). |
| Ошибка Xcode на шаге выбора | В workflow поменяйте `runner: xcode-27` → `macos-26`. |
| SideStore «Продух» / приложение исчезает через 7 дней | Wi-Fi → LocalDevVPN **Connect** → SideStore → My Apps → тап по счётчику дней (Refresh). Это ограничение бесплатного Apple ID, не сборки. |
| SideStore не устанавливает/не обновляет приложения | LocalDevVPN не подключён (нужен именно он, а не другой VPN), iPhone не в Wi-Fi, либо исчерпан лимит 3 приложений / 10 App ID в неделю. |
| Ошибка входа в Apple ID / просьба ввести код с другого устройства | Используйте официальные Anisette-серверы SideStore (настройка по умолчанию); сторонние сервера известны блокировками Apple ID. Поддержка iloader — Discord сервер idevice. |
| iloader не видит iPhone | Другой кабель (нужен data-кабель), «Доверять компьютеру», отключите Find My iPhone на время установки. |
| После обновления iOS приложения исчезли | Истёк pairing-файл → повторите установку SideStore по официальной инструкции. |
| Нужен более старый iOS | Сборка ориентирована на iOS 16.4+ (проверяется в CI); SideStore требует iOS 15.0+. |

## Запасные способы (если SideStore не подошёл)

- **Sideloadly** (Windows, есть бесплатная функция установки) — альтернатива iloader для подписи Apple ID, тот же 7-дневный лимит.
- **AltStore PAL** — требует EU Apple ID и его репозиторий принимает только notarized-источники, поэтому наш `source.json` для него не предназначен (оформлен строго под SideStore: без `marketplaceID` и `build`).
